# Практические работы по кроссплатформенной мобильной разработке

Полянский Максим Дмитриевич, ИКБО-65-23. Учебные проекты на Flutter.

- `practice2` — статический информационный экран.
- `practice3` — изображения, кастомный шрифт и управление состоянием.
- `practice4` — галерея, список карточек и уведомления.
- `practice5` — формы входа, регистрации и профиля с валидацией данных.
- `reports` — Word-отчёты по практическим работам.

Для запуска проекта откройте его папку и выполните `flutter pub get`, затем `flutter run -d chrome`. Для проверки исходников используйте `flutter analyze`.
