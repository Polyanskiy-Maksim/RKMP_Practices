Учебное приложение показывает экраны входа, регистрации и профиля. Для полей имени, email и пароля используется общий `CustomTextFormField`: он проверяет введённые значения, помогает перейти к следующему полю и позволяет показать или скрыть пароль. Данные используются только для демонстрации переходов между экранами, серверного хранения учётных записей нет.

## Структура

- `lib/pages/login_page.dart` — вход в приложение;
- `lib/pages/register_page.dart` — регистрация;
- `lib/pages/profile_page.dart` — профиль пользователя;
- `lib/widgets/text_field.dart` — повторно используемое поле с проверкой;
- `lib/main.dart` — запуск приложения и общая тема.

## Запуск

```sh
flutter pub get
flutter run -d chrome
```

Для проверки проекта:

```sh
flutter analyze
```
