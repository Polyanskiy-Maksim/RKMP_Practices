# Практические работы по кроссплатформенной мобильной разработке

Полянский Максим Дмитриевич, ИКБО-65-23. Flutter-проекты по теме «Языки программирования».

- `practice2` — статический информационный экран.
- `practice3` — пять локальных изображений, кастомный шрифт и переключение через `StatefulWidget`.
- `practice4` — горизонтальная галерея `ListView`, вертикальный список карточек и `SnackBar`.
- `reports` — Word-отчёты по работам.

Для запуска откройте нужную папку практики и выполните `flutter pub get`, затем `flutter run -d chrome`. Для проверки используйте `flutter analyze` и `flutter test`.

Готовые APK в репозиторий не добавлены из-за их большого размера. В каждом проекте есть исходники для собственной сборки командой `flutter build apk --debug`.
