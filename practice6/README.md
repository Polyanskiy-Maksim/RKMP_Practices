# Практическая работа 6

Полянский Максим Дмитриевич, группа ИКБО-65-23. Учебное приложение «Языки программирования» демонстрирует заставку, авторизацию и регистрацию, адаптивный каталог, экран описания языка и профиль. Переходы выполняются через именованные маршруты Navigator 1.0.

## Запуск

```sh
flutter pub get
flutter run -d chrome
```

Широкий экран показывает карточки каталога в два столбца; узкий — в один. Изображения и шрифт хранятся в assets.
