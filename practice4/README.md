# Практическая работа 4

Полянский Максим Дмитриевич, группа ИКБО-65-23.

Приложение продолжает тему «Языки программирования» из практических работ 2 и 3. Пять локальных изображений показаны в горизонтальном `ListView.builder` со скруглёнными углами. Ниже находится вертикальный `ListView.builder` с карточками `Card` и строками `ListTile`. При выборе карточки появляется `SnackBar` с названием языка; выбранная карточка подсвечивается.

## Запуск

```sh
flutter pub get
flutter run -d chrome
```

Проверка:

```sh
flutter analyze
flutter test
flutter build apk --debug
```

Изображения лежат в `assets/images`, шрифт заголовка — в `assets/fonts`; оба ресурса зарегистрированы в `pubspec.yaml`. Лицензия Noto Sans находится в `assets/fonts/OFL.txt`.

На macOS анализатор Dart может завершиться ошибкой, если путь к проекту содержит кириллицу. В этом случае распакуйте проект в каталог с латинским именем, например `Projects/practice4`.
