Полянский Максим Дмитриевич, ИКБО-65-23.
Тема: виджеты, дерево виджетов, StatelessWidget.
Предметная область: языки программирования.

## Запуск

Установите Flutter SDK и откройте папку проекта в Android Studio или VS Code.
В терминале из папки проекта выполните:

```sh
flutter pub get
flutter run -d chrome
```

Для запуска на Android подключите устройство или запустите эмулятор и выполните
`flutter run`, выбрав нужное устройство.

## Основные файлы

- `lib/main.dart` — полный код экрана.
- `assets/images/programming.png` — локальное изображение.
- `pubspec.yaml` — зависимости и подключение изображения.
- `test/widget_test.dart` — проверка содержимого и прокрутки.

## Проверка

```sh
flutter analyze
flutter test
```

Проверено на Flutter 3.47.5 и Dart 3.13.4: анализ без замечаний,
два теста пройдены. Приложение запускалось в Chrome.
Сборка на Android и macOS отдельно не проверялась.

Если анализатор Flutter завершается с FormatException в пути с кириллицей,
распакуйте проект в папку с латинским именем, например `Projects/practice2`.

## Дерево виджетов

Во время отладочного запуска откройте ссылку Flutter DevTools из терминала
и перейдите на вкладку Flutter Inspector.
