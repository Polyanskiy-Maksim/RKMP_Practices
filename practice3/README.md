Тема: подключение ресурсов и StatefulWidget.

Проект продолжает практическую работу 2 на тему «Языки программирования».
Заголовок использует шрифт из `assets/fonts`, а в области изображения
по кругу показываются карточки Dart, Python, Java, C++ и JavaScript.
Для переключения нажмите на изображение или кнопку.

## Запуск и проверка

Из папки проекта выполните:

```sh
flutter pub get
flutter run -d chrome
flutter analyze
flutter test
```

Для Android запустите эмулятор или подключите устройство и выберите его при `flutter run`.
Изображения находятся в `assets/images`, шрифт — в `assets/fonts`.
Все ресурсы зарегистрированы в `pubspec.yaml`.
Шрифт Noto Sans распространяется по лицензии OFL; текст лицензии лежит в `assets/fonts/OFL.txt`.

На macOS команда `flutter analyze` может завершиться ошибкой Dart analysis server,
если полный путь к проекту содержит кириллицу. В таком случае распакуйте архив
в папку с латинским именем, например `Projects/practice3`.

Проверено в Google Chrome: полный цикл пяти изображений и возврат к первому.
flutter analyze — без замечаний; flutter test — два теста пройдены.
Android debug APK собран; на Android-устройстве запуск не проверялся.
В lib/main.dart добавлены подробные комментарии для подготовки к защите.
